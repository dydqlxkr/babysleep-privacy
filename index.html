개인정보처리방침

앱 명칭: Baby Sleep (아기 수면 기록) 패키지: com.babysleep.baby_sleep 버전 기준: 1.0.0 (Phase 1) 시행일: 2026-06-04 최종 수정일: 2026-06-11

1. 개요

포근잠 개발자(이하 "개발자")이 제공하는 Baby Sleep 앱(이하 "앱")은 모든 데이터를 사용자의 기기 내부에만 저장합니다. 앱은 어떠한 서버에도 개인정보를 전송하지 않으며, 제3자 분석 도구·광고 SDK·클라우드 서비스를 사용하지 않습니다.

본 방침은 한국 「개인정보보호법」 및 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」을 준수하여 작성되었습니다.

2. 수집하는 개인정보

2-1. 앱이 서버로 전송하는 개인정보

없습니다. 앱은 인터넷 연결을 사용하지 않으며, 어떤 데이터도 외부로 전송하지 않습니다.

2-2. 사용자가 기기에 입력·저장하는 정보

사용자가 앱 내에서 직접 입력하는 아래 정보는 사용자 기기의 내부 저장소(sqflite 로컬 DB)에만 저장됩니다. 개발자는 이 정보에 접근할 수 없습니다.

항목필수 여부설명
아기 이름선택사용자가 직접 입력, 별명 사용 가능
아기 생년월일필수개월 수 계산에 사용
아기 성별선택사용자가 직접 입력
아기 몸무게선택성장 기록용
수면 세션 기록선택수면 시작·종료 시각, 메모
수유 기록선택시각, 양, 메모
기저귀 교체 기록선택시각, 종류, 메모
사진선택기록당 1장, 기기 내부 디렉터리에만 저장

2-3. 아동 개인정보에 관한 사항

본 앱은 보호자(만 18세 이상)가 영유아(0~18개월)의 생활 기록을 관리하기 위한 도구입니다. 영유아 본인이 앱을 사용하거나 직접 정보를 입력하는 구조가 아니며, 입력된 아기 정보는 보호자의 기기에만 저장됩니다. 앱은 아동 본인의 계정을 생성하거나 아동의 개인정보를 수집·전송하지 않습니다.

3. 개인정보의 이용 목적

기기에 저장되는 정보는 다음 목적으로만 사용됩니다.

  • 아기의 수면·수유·기저귀 교체 기록 조회 및 통계 표시
  • 기록 간 패턴 분석(기기 내 연산)

4. 개인정보의 보유 및 파기

  • 보유 기간: 사용자가 앱을 삭제하거나 앱 내 데이터 삭제 기능을 사용하기 전까지 기기에 보관됩니다.
  • 파기 방법: 앱 삭제 시 운영체제(Android)의 정책에 따라 앱 데이터가 즉시 삭제됩니다. 앱 내에서도 개별 기록 및 전체 데이터를 직접 삭제할 수 있습니다.
  • 개발자 서버에는 어떠한 데이터도 보관되지 않으므로 별도의 서버 측 파기 절차가 존재하지 않습니다.

5. 개인정보의 제3자 제공

개발자는 사용자의 개인정보를 어떤 제3자에게도 제공하지 않습니다. 앱은 제3자 분석 SDK, 광고 네트워크, 소셜 로그인 연동이 없으며 데이터를 외부로 전송하지 않습니다.

6. 개인정보 처리 위탁

위탁하는 업무 없음. 앱 운영에 제3자 처리 위탁이 발생하지 않습니다.

7. 이용자의 권리

사용자는 다음 권리를 행사할 수 있습니다.

권리행사 방법
열람앱 내 기록 화면에서 직접 확인
수정앱 내 편집 기능을 통해 직접 수정
삭제앱 내 삭제 기능 또는 앱 삭제로 전체 삭제
처리 정지앱 사용 중단(로컬 처리이므로 별도 정지 요청 불필요)

개발자 서버에는 데이터가 없으므로 외부 삭제 요청 절차는 불필요합니다. 문의 사항이 있으면 아래 연락처로 연락하십시오.

8. 안전성 확보 조치

  • 모든 데이터는 사용자 기기의 내부 저장소에 저장됩니다 (외부 앱 접근 불가).
  • 현재(Phase 1) 로컬 DB(sqflite)에 별도 암호화는 적용하지 않습니다. 기기 잠금(PIN/생체인증)을 통해 기기 수준의 보안이 제공됩니다.
  • 향후 단계(Phase 3)에서 SQLCipher 기반 DB 암호화 도입을 검토할 예정입니다.
  • 네트워크 전송이 없으므로 전송 구간 침해 위험이 없습니다.

9. 앱 권한 사용

앱이 요청하는 권한과 사용 목적은 다음과 같습니다.

권한사용 목적
카메라 (CAMERA)사용자가 기록에 사진을 첨부할 때, 카메라로 직접 촬영하는 경우에만 사용. 자동 촬영·백그라운드 실행 없음

11. 방침의 변경

본 개인정보처리방침은 법령 변경, 서비스 기능 추가, 정부 지침 등에 따라 변경될 수 있습니다.

  • 변경 시 앱 스토어 업데이트 노트 및 본 정책 페이지를 통해 사전 고지합니다.
  • 중요 변경(데이터 수집·공유 항목 추가 등)은 변경일 30일 전 고지를 원칙으로 합니다.
  • 변경된 방침은 고지 후 앱 업데이트 시 적용됩니다.
